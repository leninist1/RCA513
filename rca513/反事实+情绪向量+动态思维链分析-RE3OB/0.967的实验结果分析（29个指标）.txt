三类故障的本质差异
类型	特征	为什么需要不同策略
Type A 帕累托单点型	Top-1影响力断崖式领先，基尼系数>0.7	信号极其明确，不需要复杂推理，直接影响力排序即可
Type B 双头博弈型	两个候选影响力接近，但Recovery分数有差异	Top-1和Top-2纠缠，需要用反事实做"二元淘汰"——只比较两个候选谁修复后全局恢复更好，而非全排序
Type C 混沌共振型	所有候选影响力扁平，区分度低	图结构信号失效，需要补充日志语义+Metrics时序突变来补全弱信号
为什么这比"一套公式"好
Type A如果也做反事实验证，浪费时间还容易误判（因为Hub节点修复后全局恢复总是很高）

Type B如果只按影响力排序，Hub节点永远第一，但真正的根因可能是排名第二的那个

Type C如果只靠图结构，所有候选分数接近，随机选一个=撞大运；加入日志和时序信号后能把真正有异常的节点拉出来
